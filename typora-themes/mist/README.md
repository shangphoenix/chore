# Mist

`mist.css` 是基于 Typora 内置 GitHub Theme 修改的自用主题，不是官方主题。

主要调整：

- 绿色引用块
- 蓝色行内代码
- 柔和暖黄色高亮
- 适合个人 Markdown 阅读和写作的细节样式

## 使用

1. 在 Typora 中打开“偏好设置 → 外观 → 打开主题文件夹”。
2. 将 [`mist.css`](./mist.css) 放入主题文件夹。
3. 重启 Typora，并在“主题”菜单中选择 `Mist`。

主题引用了 GitHub Theme 使用的字体资源路径；如果本地缺少对应资源，Typora 会回退到系统字体。
